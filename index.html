How to use it

  • Sit the question paper first, under the clock. Then mark yourself against the solutions.
  • Each answer runs Question → Formula used → Answer → Why → NCERT. In a numerical the method carries most of the marks, so the formula is shown before any arithmetic.
  • Click any green Ch N, p. NN button to open the NCERT chapter beside the answer, at that page.

Serving this folder

  • Push the whole folder to a GitHub repository and turn on GitHub Pages; everything is static and relative, so it works as-is.
  • To read it locally, serve it rather than opening the file directly: python3 -m http.server in this folder, then visit localhost:8000. Opening index.html straight from disk works too, but some browsers refuse to draw a PDF inside the side panel over file:// — the Open in new tab button in the panel covers that case.
